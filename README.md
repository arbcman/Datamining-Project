## Overview

This project explores three core data mining paradigms using real-world-inspired datasets:

| Task | Problem | Technique | Goal |
|------|---------|-----------|------|
| Classification | Network Intrusion Detection (NIDS) | Supervised classification | Detect normal vs. malicious network traffic |
| Regression | Student Performance Prediction | Supervised regression | Predict student academic performance from relevant features |
| Association Rules | Market Basket Analysis | Unsupervised pattern mining | Discover frequent itemsets and purchase associations |

## Projects

### 1. Classification: Network Intrusion Detection System (NIDS)

**Objective:** Build and evaluate classification models to identify network intrusions from traffic features.


---

### 2. Regression: Student Performance Prediction

**Objective:** Predict student performance (e.g., final grade/score) based on academic, demographic, or behavioral features.


---

### 3. Association Rules: Market Basket Analysis

**Objective:** Discover meaningful relationships between items purchased together using association rule mining.
